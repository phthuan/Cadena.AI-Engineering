# Fix Bug

1. Reproduce the issue where possible.
2. Trace the actual call path and inspect relevant methods, queries and logs.
3. Read applicable shared rules under rules/common/ and rules/bug-fixing/.
4. Separate confirmed facts from hypotheses.
5. Identify the root cause before editing code.
6. Implement the smallest safe fix without unrelated refactoring.
7. Add a regression test where practical.
8. Run relevant checks and report actual results.
9. Summarize the root cause, changes, risks and remaining uncertainties.
